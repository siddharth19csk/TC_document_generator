OneStream XF Ready

1. Overview & Purpose

The Testcase Document Generator is a specialized automation tool designed for OneStream development teams, reviewers, and business analysts. It converts ServiceNow tickets, daily activity notes, or developer logs into an officially formatted Word testcase review checklist (.docx) compliant with corporate governance requirements.

Website URL: https://tc-document-generator.onrender.com

2. Navigating the Interface

The interface is streamlined to collect minimal required metadata while allowing complete flexibility in your input description.

Figure 1: Application homepage showing required input fields.

Field Descriptions:

  • Testcase Raw Details (Required): Paste the complete ServiceNow change/incident description, developer notes, or prompt detailing modified OneStream artifacts and workflow changes. Minimum 10 characters.
  • Report Code (Required): Enter the primary report or artifact code (e.g. R117, PWRJOB_RPT_15, or RPT_FORECAST).
  • Certified By (Required): Developer name (e.g. Siddharth Chandran). Mandatory – stamped on the certification block of the generated document.
  • Ticket Number (Required): ServiceNow tracking ticket (e.g. CHG0058275, INC0158214, or RITM0098421).
Figure 2: Form populated with ticket details and certified reviewer information.

5. Generating & Downloading

Figure 3: Generation complete screen with instant download action.
  1. Click Generate OneStream Document.
  2. Wait 3-5 seconds while the document is synthesized and structured into tables.
  3. Click Download Document to receive your standard corporate Word file (.docx).
